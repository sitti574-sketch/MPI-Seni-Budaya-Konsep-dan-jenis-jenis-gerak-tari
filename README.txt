MPI SENI BUDAYA — KONSEP GERAK DAN JENIS-JENIS GERAK
Pengembang: SITTI NURUL HAERATI ANSAR, S.Pd
Sekolah: SMP NEGERI 8 KOLAKA UTARA
Sasaran pada tampilan: Kelas VIII, Fase D, Kurikulum Merdeka

ISI ZIP
- index.html : halaman MPI
- style.css  : tampilan responsif
- app.js     : interaksi, asesmen, simulasi, kuis, refleksi lokal

CARA MENJALANKAN OFFLINE
1. Ekstrak file ZIP ke sebuah folder.
2. Buka index.html dengan Chrome, Edge, Firefox, atau browser modern.
3. Internet tidak diperlukan untuk fitur inti. Google Font mungkin tidak dimuat tanpa internet; browser memakai font cadangan.
4. Audio narasi memakai fitur text-to-speech bawaan browser/perangkat dan ketersediaannya bergantung pada perangkat.

CARA MEMBUAT ONLINE
Pilihan A — GitHub Pages
1. Buat akun/login di GitHub.
2. Buat repository baru, misalnya mpi-gerak-seni-budaya.
3. Unggah index.html, style.css, app.js (dan README bila diperlukan) ke root repository.
4. Buka Settings > Pages, pilih deploy dari branch utama (root), lalu simpan.
5. Tunggu URL Pages muncul. Uji melalui HP dan komputer.

Pilihan B — Hosting statis lain
Unggah semua file ke root folder public_html atau direktori situs statis pada layanan hosting yang digunakan. Pastikan index.html berada di folder utama situs.

CATATAN
- MPI ini adalah aplikasi web statis; tidak memerlukan server/database.
- Skor dan aktivitas berjalan lokal di browser. Refleksi disimpan menggunakan localStorage pada perangkat/browser yang sama.
- Data tidak otomatis terkirim kepada guru. Untuk pengumpulan nilai jarak jauh diperlukan backend, formulir daring, LMS, atau integrasi tambahan.
- Materi memakai istilah lokomotor, nonlokomotor, dan manipulatif sesuai fokus PJOK yang diminta dalam prompt; halaman identitas tetap mengikuti permintaan Seni Budaya kelas VIII.
- Simulasi berupa ilustrasi emoji dan animasi sederhana, bukan model 3D atau video gerak nyata.
